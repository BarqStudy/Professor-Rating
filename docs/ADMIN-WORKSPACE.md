# لوحة تحكم مِعيار

تفتح لوحة الإدارة للأدمن المتحقق فقط من قائمة المنصة. تبدأ الحسابات الجديدة بنظرة عامة، ويُحفظ آخر قسم وأداة فتحهما الأدمن تحت مفتاح خاص بحسابه. اختيار تخصص الطالب لا يعطل وصول الأدمن لأدوات الإدارة.

| القسم | الأدوات |
| --- | --- |
| نظرة عامة | أعداد الطلبات الحالية، واختصارات للأعمال الشائعة |
| الطلبات والمراجعة | التقييمات الجديدة، إضافة دكتور، الجامعات والكليات، تعديل تقييم، البلاغات، تصحيح بيانات الدليل |
| الجامعات والكليات | إضافة الجامعات وتفعيلها، الكليات، التخصصات |
| الدكاترة | إضافة فردية أو دفعة واحدة، البحث والتوثيق والمناصب والأرشفة |
| الخطط والمقررات | تعديل الخطط والمقررات واسم الخطة أو حذفها، واستيراد خطة جديدة |
| التقييمات المنشورة | البحث والتصفية والصفحات وحذف تقييم بعد تأكيده |
| الفريق والمستخدمون | تعيين السفراء والمساعدين، وإدارة حالة الحسابات وجلسات الزائر |
| ملفات المنصة | رفع الملفات وتنزيلها وفحص تخزين R2 |
| الربط والإعدادات | إعداد بريد الطلبات وفحص الاتصال، وفحص المساعد |

البحث أعلى اللوحة يبحث في أسماء الإجراءات ومرادفاتها، مثل «حذف تقييم» و«تعديل خطة» و«تعيين مساعد» و«بريد». يفتح الاختصار القسم والأداة المقصودة دون إرسال نموذج أو تنفيذ إجراء إداري. الموافقات والحذف والحفظ تظل عبر أزرارها المعتادة.

تبديل الأقسام يخفي الأدوات الأخرى مع الاحتفاظ بعناصر النماذج نفسها، بما فيها النصوص والملف المختار ومسودة محرر الخطة. لا يحمّل محرر الخطط أو قائمة الملفات من الخادم حتى يفتح الأدمن أداتهما. لا تُطلب أدوات الإدارة أو بياناتها للحسابات غير الإدارية. لا تُغير إعادة الترتيب صلاحيات الخادم أو مسارات API.

شريط الأقسام ثابت على الكمبيوتر، وقابل للتمرير الأفقي أسفل ترويسة المنصة على الشاشات الصغيرة. يعاد حساب موضعه عند تغيير حجم النافذة، وتُزال مراقبة الحجم عند مغادرة اللوحة. أعداد الطلبات مأخوذة من القائمة الحالية؛ يظهر عدم توفر العدد عند فشل تحميله بدل عرض صفر مضلل.

التحقق: `npm test`، و`node tests/browser/admin-workspace.cjs`، و`node tests/browser/published-reviews.cjs`، واختبار الأداء. اختبارات المتصفح تستعمل API وهوية محاكاة، ولا تعدل تقييمات أو بيانات إنتاجية.
