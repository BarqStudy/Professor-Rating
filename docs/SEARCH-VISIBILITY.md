# ظهور مِعيار في البحث

الرابط الأساسي هو `https://miyar.website/`. الصفحة الرئيسية تحتوي على عنوان ووصف عربيين، ورابط canonical، وبيانات WebSite لاسم المنصة، ومعلومات مشاركة الروابط. ملف `public/robots.txt` يسمح بالزحف ويشير إلى `public/sitemap.xml`. الخريطة تشمل الصفحات العامة الفعلية فقط، دون مسارات الحساب أو الإدارة أو روابط الأقسام التي تبدأ بـ `#`.

## تفعيل Google Search Console

1. افتح [Google Search Console](https://search.google.com/search-console/welcome) بحساب مالك المنصة.
2. أضف موقعًا من نوع **Domain** باسم `miyar.website`، دون `https://` أو مسار.
3. انسخ سجل TXT الذي يقدمه Google وأضفه في إعدادات DNS عند مزود النطاق، ثم اضغط **Verify**. أضف سجلًا جديدًا واترك سجلات الموقع والبريد الحالية كما هي.
4. من **Sitemaps** أرسل `https://miyar.website/sitemap.xml`.
5. افحص `https://miyar.website/` في **URL inspection**، واستخدم **Test live URL** ثم **Request indexing** إذا كانت الصفحة متاحة للفهرسة.
6. تابع تقارير **Page indexing** و**Performance** لمعرفة الصفحات المفهرسة وكلمات البحث والظهور والنقرات. لا تكرر طلب الفهرسة يوميًا؛ لا يضمن الطلب الفهرسة أو ترتيبًا محددًا، وقد يستغرق التحديث أيامًا أو أسابيع أو أكثر.

يمكن استخدام خاصية URL prefix والتحقق بملف HTML إذا لم يتوفر وصول إلى DNS؛ ملف التحقق الذي يقدمه Google يوضع داخل `public/` ويُنشر، ثم يُتحقق من عنوانه قبل الضغط على Verify. لا تستبدل صفحة المنصة بملف التحقق.

## حدود الواجهة الحالية

المنصة تعتمد على JavaScript لاختيار الجامعة وتحميل الدكاترة. يمكن لـ Google معالجة JavaScript، لكن العنوان والوصف وخريطة الموقع وحدها لا تنشئ نتائج مستقلة لكل دكتور. روابط المشاركة الحالية مثل `?doctor=123` تفتح التطبيق نفسه؛ ليست صفحات تعريف ثابتة مستقلة، ولذلك لا تُضاف آليًا إلى الخريطة.

لإظهار نتائج مستقلة عند البحث باسم الدكتور، يلزم عمل صفحات عامة بروابط دائمة لكل دكتور، بمحتوى HTML قابل للقراءة قبل تشغيل JavaScript: اسمه وجامعته وكليته ومواده والتقييمات المعتمدة فقط، مع روابط داخلية قابلة للزحف وcanonical خاص بكل صفحة. يجب أن تتحدث الصفحات عند تعديل السجل أو إزالة الدكتور أو تقييمه، وألا تنشر بيانات هوية الطلاب أو التقييمات المعلقة. لا تُولّد صفحات فارغة أو تقييمات أو نجوم غير موجودة.

المحتوى المفيد والتقييمات الفعلية وروابط من جهات طلابية ذات صلة تساعد بمرور الوقت. لا تضمن أي إضافة برمجية الوصول لترتيب منصة أخرى، ولا تتطلب الفهرسة شراء إعلان.
