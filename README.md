# مِعيار | Miyar

منصة ويب عربية لتقييم دكاترة الجامعة، بتسجيل دخول **Google فقط** عبر Supabase Auth، وواجهة Vite وقاعدة PostgreSQL ودالة خادم لحماية العمليات.

**[خطوات تفعيل Google والخادم مجانًا](docs/FREE-SETUP.md)** — الروابط مضبوطة لمشروع `bbnsorjxgehvoddluvyo`. يحتاج مالك المشروع إعداد Google OAuth داخل Google Cloud وSupabase، ثم نشر قاعدة البيانات والخادم.

## التشغيل

```sh
npm ci
npm test
npm run dev
npm run build
```

لتجربة نسخة العرض المحلية دون اتصال استخدم `VITE_DEMO_MODE=true npm run dev`. في الوضع الفعلي تظهر أخطاء الاتصال بدل الرجوع إلى بيانات نموذجية.

## السلوك

- الزائر يتصفح الدكاترة والتقييمات. الإرسال والملف الشخصي يتطلبان الدخول بـGoogle.
- تستعمل المصادقة PKCE مع استعادة الجلسة وتجديدها والخروج عبر Supabase SDK. الخادم يتحقق من التوكن لدى Supabase Auth ومن هوية Google وطريقة OAuth، ولا يثق بدور أو معرّف أرسله المتصفح.
- الدكاترة الجدد والتقييمات بانتظار المراجعة؛ قبول الدكتور لا ينشر التعليقات تلقائيًا.
- المعدلات والإحصاءات مشتقة من التقييمات المنشورة. تشمل الإدارة الكليات والتخصصات والدكاترة والتوثيق والحظر والتقييد، والصلاحيات محددة على الخادم بـ`ADMIN_AUTH_IDS`.
- هوية الطالب وبريده ودرجته لا تظهر في التقييمات العامة. الدرجة لا تظهر في شاشة مراجعة التعليقات. مالك قاعدة البيانات لديه وصول إداري للبيانات.
- ملف الطالب على الخادم، والمحفوظات والمظهر وحجم الخط على الجهاز.
- واجهة عربية RTL مع خط «ثمانية» المرفق ووضعين نهاري وليلي.

## الإعدادات

`src/config.js` يحتوي رابط المشروع ومفتاح Publishable العام اللذين وفرهما المالك. يمكن تجاوزهما بـ`VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY`. لا تضف مفتاح خدمة أو Google Client Secret أو توكن إدارة إلى كود المتصفح أو متغيرات `VITE_`.

Google Client Secret يُحفظ في إعداد Google provider داخل Supabase فقط. نشر الخادم يحتاج `SUPABASE_ACCESS_TOKEN` و`SUPABASE_DB_PASSWORD` في GitHub Secrets. دليل التفعيل يشرح الخطوات والعناوين بالتفصيل.

## قاعدة البيانات والاختبارات

الترحيل الثاني يضيف حسابات Google وقيودها دون حذف البيانات التاريخية أو تغيير ملكيتها. ملفات الترحيل الأولى تبقى كسجل تاريخي؛ التطبيق لم يعد يقبل دخولًا أو إرسالًا عبر البوت.

`npm test` يختبر حدود المصادقة والصلاحيات والخصوصية والمدخلات، ويطبّق الترحيلات على PostgreSQL عبر PGlite للتحقق من حفظ البيانات والقيود وحدود الإرسال. لا يغني هذا عن تجربة OAuth حقيقية بعد تفعيل مزود Google في حساب المالك.

الواجهة تُنشر على GitHub Pages عبر **Deploy Miyar to GitHub Pages**. ترحيل قاعدة البيانات ونشر الدالة عبر **Set up Miyar backend**. الخدمات المجانية لها حصص استخدام وقد يتوقف المشروع غير النشط مؤقتًا.

لفحص الواجهة بمصادقة وشبكة محاكاتين: `npm run test:browser`. يحتاج متصفح Chromium مثبتًا؛ يمكن تحديد مساره بـ`CHROMIUM_PATH`. يشمل الفحص رجوع OAuth عبر PKCE واستعادة الجلسة والخروج ومنع الإرسال كزائر، ولا ينفذ دخولًا حقيقيًا إلى Google.

عرض الدكاترة في منزلق أفقي يدعم السحب وأزرار السابق والتالي، مع اختيار الكلية لإظهار أزرار تخصصاتها. يظهر الرسم الترحيبي على الجوال، وتوجد إعدادات الطالب في زر إعدادات واحد بعد تسجيل الدخول. مؤشرات التقييم تستخدم محورًا من اليسار إلى اليمين: ٠ أحمر و١٠٠ أخضر، مع لون مستقل لكل فئة تقييم.

### الواجهة الزجاجية والإضافة الجماعية

الواجهة تدعم Liquid Glass في الوضعين النهاري والليلي، مع خلفية ضبابية وتعطيل التفاعل خلف البطاقات المفتوحة. للتقييمات رابط `#ratings` ولإضافة التقييم `#review`، مع دعم الرجوع وإعادة التحميل. من لوحة الإدارة اختر تخصصًا والصق حتى ١٠٠ اسم ثلاثي، كل اسم في سطر. تُضاف الدكاترة عبر صلاحيات الأدمن الحالية دون إنشاء تقييمات؛ تُستبعد الأسماء المكررة محليًا، وتبقى بقية الأسماء عند فشل الاتصال لإعادة المحاولة.

### الجامعة الخاصة بكل طالب

بعد تسجيل الدخول يختار الطالب جامعة إلزاميًا. يُحفظ الاختيار في حسابه ويمكن تغييره من الإعدادات؛ عند تغييره يُصفّر تخصصه السابق. تُصفّى كليات الطالب ودكاترته والبحث والمحفوظات حسب الجامعة، بينما تبقى لوحة الإدارة قادرة على إدارة الجامعات كلها. الجامعات الأولية: الملك سعود، الملك خالد، ونجران؛ البيانات السابقة تتبع نجران حسب تأكيد المالك. تسمح قاعدة البيانات بتكرار اسم الكلية بين جامعات مختلفة وتتحقق من انتماء التخصص والتقييم للجامعة الصحيحة.

تغييرات `supabase/**` تُشغّل إجراء إعداد الخادم تلقائيًا لتطبيق الترحيلات ونشر الدالة، باستخدام أسرار GitHub الحالية. يبقى التشغيل اليدوي متاحًا. الواجهة تتوافق مؤقتًا مع الخادم السابق إلى أن يكتمل نشره.
