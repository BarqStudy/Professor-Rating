# مِعيار | Miyar

منصة عربية لتقييم دكاترة الجامعة، بواجهة Vite وخادم Supabase يتحقق من حسابات Telegram Mini App.

**[خطوات تفعيل المنصة مجانًا](docs/FREE-SETUP.md)** — يتطلب إنشاء مشروع Supabase وبوت Telegram وإدخال الأسرار في إعدادات GitHub. وجود الكود لا يعني أن قاعدة بيانات حية نُشرت.

## التشغيل والتحقق

```sh
npm ci
npm test
npm run dev
npm run build
```

تستخدم الواجهة ملفات خط «ثمانية» المرفقة محليًا. تدعم العربية وRTL والوضع الليلي وتعديل حجم الخط والملف الشخصي والحفظ والمشاركة.

## وضعا التشغيل

- دون `VITE_SUPABASE_URL`: نسخة عرض واضحة ببيانات نموذجية وتخزين محلي. الإدارة التجريبية متاحة أثناء التطوير المحلي فقط.
- بعد التفعيل: دليل وتقييمات مشتركة في قاعدة البيانات، وإرسال موقّع من Telegram، وملف طالب محفوظ على الخادم. الإدارة لا تظهر إلا لحساب أدمن تحقّق منه الخادم. عند فشل الاتصال يظهر خطأ بدل استخدام بيانات وهمية.

تقييمات الدكتور الجديد وطلب إضافته بانتظار المراجعة. موافقة الدكتور لا تنشر تعليقاته تلقائيًا؛ للأدمن مراجعة منفصلة للتعليقات. المعدلات والإحصاءات مشتقة من التقييمات المنشورة فقط. تشمل الإدارة الكليات والتخصصات والدكاترة والتوثيق والحظر والتقييد.

## الملفات

- `src/`: الواجهة والاتصال بالخادم؛ لا تُخزّن فيها الأسرار.
- `supabase/migrations/`: الجداول والصلاحيات ودوال الإرسال والتجميع.
- `supabase/functions/miyar/`: التحقق من Telegram وواجهة العمليات المحمية.
- `tests/`: اختبارات التوقيع والصلاحيات والخصوصية والتحقق من المدخلات، واختبار ترحيل PostgreSQL باستخدام PGlite.
- `.github/workflows/`: نشر الواجهة، وإعداد الخادم يدويًا باستخدام أسرار الحساب.

## النشر

GitHub Pages → Source → **GitHub Actions**. نشر الواجهة عبر **Deploy Miyar to GitHub Pages**؛ تجهيز Supabase عبر **Set up Miyar backend**. انظر الدليل للإعدادات والتسلسل الصحيح.

لا تحتاج شراء دومين. الخدمات المجانية لها حدود وقد يتوقف مشروع قاعدة البيانات غير النشط. لا تدّعي المنصة أن البيانات مخفية عن مالك قاعدة البيانات؛ الهوية والدرجة لا تظهران في العرض العام أو شاشة مراجعة التعليقات.
