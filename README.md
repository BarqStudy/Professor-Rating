# مِعيار | Miyar

واجهة عربية متجاوبة لمنصة تقييم دكاترة الجامعة، مبنية باستخدام JavaScript وVite.

## التشغيل

```sh
npm ci --cache /tmp/athar-npm-cache
npm run dev -- --port 5173
```

لبناء نسخة الإنتاج: `npm run build`. لمعاينتها: `npm run preview`.

## الميزات

- هوية وشعار أصليان باستخدام CSS، ودعم اتجاه RTL والوضعين النهاري والليلي.
- البحث بأسماء الدكاترة والمواد، والتصفية حسب الكلية والتخصص.
- نموذج تقييم بثلاثة مؤشرات من 0 إلى 100، وتعليق، وطلبات إضافة دكتور.
- حفظ الدكاترة، ومشاركة روابط تفاصيلهم، وصفحة المطور.
- إدارة محلية تجريبية للكليات والتخصصات والدكاترة والتوثيق والطلبات وحالات المستخدمين.
- قراءة بيانات مستخدم Telegram Web App عند توفرها. داخل تيليجرام تُخفى الإدارة التجريبية.

## حدود النسخة

هذه واجهة تجريبية: البيانات الأولية والإحصاءات توضيحية، والبيانات المضافة محفوظة في `localStorage` على الجهاز فقط. درجة الطالب لا تُخزّن. الفلترة المحلية قائمة كلمات بسيطة ولا تكفي للإشراف على منصة فعلية.

قبل النشر يلزم خادم وقاعدة بيانات والتحقق من توقيع Telegram `initData` وصلاحيات الأدمن، والتحقق من المدخلات والفلترة على الخادم وتطبيق الحظر والتقييد فعليًا. لا تعتمد على معلومات المستخدم في المتصفح لمنح الصلاحيات. لا تدخل بيانات حساسة في النسخة التجريبية.

تستخدم الواجهة ملفات خط «ثمانية» التي وفّرها المستخدم، المستضافة محليًا في `public/fonts`، بأوزان Light وRegular وMedium وBold وBlack، دون الاعتماد على Google Fonts. مكتبة Telegram الرسمية محملة من `telegram.org`.

فحوص التحقق المنفذة: بناء الإنتاج، صحة JavaScript، استجابة خادم التطوير، وفحص DOM تفاعلي للبحث والحفظ والتقييم واستبعاد الدرجة ورفض الكلمات المسيئة والإدارة وتبديل المظهر.

## النشر على GitHub Pages

من إعدادات المستودع افتح **Pages → Build and deployment → Source** واختر **GitHub Actions**.
سير العمل `Deploy Athar to GitHub Pages` يبني المشروع وينشر مجلد `dist` عند كل رفع إلى `main`؛ ويمكن تشغيله يدويًا من تبويب Actions. لا تنشر ملفات المصدر مباشرةً باستخدام Deploy from a branch.
المسار الأساسي مضبوط على `/Professor-Rating/`، بما يطابق رابط المستودع على GitHub Pages.

## إعدادات الطالب

زر الإعدادات أعلى الشاشة يتيح تعديل الاسم والتخصص والمستوى (١–١٢)، وتغيير حجم النص بين ٩٠٪ و١٣٠٪ مع معاينة فورية. تحفظ التفضيلات محليًا وتبقى بعد إعادة التحميل. تسجيل الخروج يمسح الملف المحلي، مع إبقاء حجم الخط والمظهر، ويتيح الدخول مجددًا أو التصفح كزائر؛ لا يسجل الخروج من حساب تيليجرام.
